# PyLoxone-Audio 0.1.5

Library **0.1.5** · reference adapter **0.1.5** · frontend **r13**, based on PyLoxone **0.10.3**.
Install the matching component and frontend; installing the library alone does not update the integration.

[Install or upgrade](https://github.com/davehocking/PyLoxone-Audio/blob/main/preview-build/README.md), then set **Audioserver host** and enable **Use Audio Server player play/pause (experimental; off by default)** in the existing Loxone entry. Diagnostics is separate and optional.
