# Changelog

## 0.1.7

- Matching library/adapter 0.1.7 and frontend r14.
- Nested Library browsing and native Core 2026.11.1 Group compatibility.
- Native room-only volume, explicit balanced group volume, follower controls and 300 ms tap batching.

## 0.1.6

- Reuse the entry-owned authenticated command connection to reduce warm command and catalogue wait-time.
- Keep fresh mapped playback sessions; otherwise expire after five minutes without meaningful activity.
- Retain request serialization, native proof, revocation and no-replay safeguards; unchanged r13 frontend.


## 0.1.5

- Matching library and reference adapter 0.1.5 with frontend r13.
- Short installation and maintainer guides, with an upgrade from the previous public adapter.

## 0.1.4.post1

- Documentation and packaging revision of library 0.1.4, paired with reference adapter 0.1.4 and the exact library requirement `PyLoxone-Audio==0.1.4.post1`. Audio behaviour and frontend r12 are unchanged.

## 0.1.4

- Longer bounded feedback waits for large serially qualified audio groups.
- Full-width group/member volume sliders with percentage and −/+ controls.
- Original release: library 0.1.4, reference adapter 0.10.3.dev19 and frontend r12 on stock PyLoxone 0.10.3.

[Current release notes](https://github.com/davehocking/PyLoxone-Audio/blob/main/RELEASE-NOTES-0.1.7.md). Earlier releases remain in Git history and GitHub Releases.
